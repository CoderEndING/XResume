# 汪子轩 - 个人简历（网页版）

参照 [CoderEndING/resume](https://github.com/CoderEndING/resume) 模板风格制作：左侧信息栏 + 右侧主栏，青绿色主题（#00796b），微软雅黑字体。

## 文件说明

- `index.html` — 简历内容（左侧栏：基本信息/联系方式/论文发表/获奖证书/自我评价；主栏：教育背景/工作经历/项目经历/专业技能）
- `style.css` — 页面样式，内含 `@media print` 打印样式
- `汪子轩-嵌入式软件工程师-简历.pdf` — 已导出的 A4 两页 PDF

## 使用方法

1. **浏览**：直接双击 `index.html` 用浏览器打开即可；
2. **导出 PDF**：在浏览器中按 `Ctrl+P` 打印，选择"另存为 PDF"，纸张 A4、边距默认、勾选"背景图形"即可（打印时自动切换为紧凑的单栏排版）。

## 修改内容

直接编辑 `index.html` 中对应区块的文本即可，无需动 CSS。
